# VV-Lab-SP-24-BSSE-104-PSVS

## Project Overview
This repository contains the Software Verification and Validation (V&V) lab assignment for the Polar Seed Vault System (PSVS).

## Objectives
- Establish configuration management and version control.
- Analyze informal requirements for defects.
- Develop a defect taxonomy and verification log.
- Conduct peer review and calculate defect detection rates.
- Summarize defects using tables and charts.

## Repository Structure
- `requirements/` — System requirements and baseline.
- `defect-logs/` — Defect taxonomy, defect log, and peer-review comparison.
- `abstractions/` — System abstractions.
- `models/` — System models.
- `operations/` — Operational specifications.
- `constraints/` — System constraints.
- `proofs/` — Verification proofs.
- `reports/` — Defect summaries and charts.
